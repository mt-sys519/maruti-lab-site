「BILLIARDS」のONLINE VSなら、**部屋のURLを友達に送るだけで、離れていてもビリヤードの対戦ができます**。アプリのインストールも会員登録もいらず、ブラウザで開くだけなので、スマホとパソコン、iPhoneとAndroidのような組み合わせでもそのまま対戦できます。

## 部屋を作って、URLをLINEなどで送る

部屋を作る人と、URLを開く人の2人で遊びます。始め方はこれだけです。

1. BILLIARDSを開き、最初の画面の上で9-BALLか8-BALLを選ぶ
2. 「ONLINE VS」を選び、1 RACK（1ラック勝負）かRACE TO 3（3ラック先取）を選ぶ
3. 「CREATE ROOM」を押すと、その部屋のURLが出る
4. 「SEND LINK」を押して、LINEやメールで相手に送る
5. 相手がURLを開いたら、そのまま試合が始まる

スマホでは「SEND LINK」を押すと共有の画面が開くので、LINEなどをそのまま選べます。パソコンではボタンが「COPY LINK」になっていて、押すとURLがコピーされます。**相手はURLを開くだけで、何も選ばなくて大丈夫です**。

![左は部屋のURLとCOPY LINKのボタンが出たONLINE VSの画面、右はURLを開いた側の台の画面で、下に「相手が狙っています」と出ている](/blog/billiards-online-pair.webp)
*左がCREATE ROOMを押したところ。右はそのURLを開いた側で、相手のブレイクを待っています*

<div class="kome"><p>9ボールか8ボールか、何ラック勝負かは、部屋を作った人が決める。URLを開いた側の画面には、決まった内容が試合の始めに出る。</p></div>

## スマホとパソコン、iPhoneとAndroidでもクロスプレイできる

BILLIARDSはアプリではなくWebページなので、**端末の種類を問わずに対戦できます**。相手がどの端末を使っているかを気にする必要はありません。

| 自分 | 相手 | 対戦 |
| --- | --- | --- |
| iPhone | Android | できる |
| スマホ | パソコン | できる |
| パソコン | パソコン | できる |
| タブレット | スマホ | できる |

ブラウザはSafariでもChromeでもかまいません。スマホは指で、パソコンはマウスで、同じように引いて離して撞きます。パソコンでは、右ボタンを押したままドラッグすると、引く前にキューの向きを合わせられます。

## つながったら、部屋を作った人のブレイクから

相手がURLを開いた時点で試合が始まり、**最初のブレイクは部屋を作った人**です。

対戦はそれぞれ自分の画面で遊びます。相手の番のあいだは「相手が狙っています」と出て、相手のキューが動くのがそのまま見えます。どこを狙っているのか、だいたい分かるのがおもしろいところです。

打ち方は一人で遊ぶときと同じで、引いているあいだ右のゲージが上下し、離したときの強さで撞きます。左下の手玉をタップすると、押し・引き・ひねりの撞点も選べます。

## 途中で切れても台はそのまま残る

電車の中などで通信が途切れることもあります。そのときは「DISCONNECTED」と出ますが、**台の玉の配置はそのまま残っていて、自動でつなぎ直します**。つながらないときは「RECONNECT」を押せば、同じ部屋に入り直せます。

試合が終わったら「REMATCH」で、同じ相手ともう一戦できます。どちらが押してもよく、次のブレイクは前の試合で負けた人です。

| 困ったとき | どうなるか |
| --- | --- |
| 「この部屋は満員です」と出た | 1つの部屋に入れるのは2人まで。新しく部屋を作ってもらう |
| 相手がなかなか来ない | 相手がURLを開くまで待っている。送ったURLが届いているか確かめる |
| 途中で切れた | 自動でつなぎ直す。だめならRECONNECTを押す |

## 同じ場所にいるなら、1台を交互に使うLOCAL VS

並んで座っているなら、通信なしの「LOCAL VS」が手軽です。**スマホやパソコン1台を、打つ番の人に渡しながら遊びます**。画面の上にはP1とP2のどちらの番かが出るので、取り違えることもありません。

| 遊び方 | 向いている場面 |
| --- | --- |
| ONLINE VS | 離れている友達と。それぞれ自分のスマホやパソコンで |
| LOCAL VS | 隣にいる人と。1台を交互に渡して |
| VS CPU | 一人で。EASY・NORMAL・HARDの3段階 |
| SOLO | 一人で、何打で取り切れるかを数える |

ナインボールは一番小さい番号の玉から当てて、9番を落とせば勝ち。エイトボールはコールなしで、自分の組（ソリッドかストライプ）を全部落としてから8番を落とせば勝ちです。ルールに自信がなくても、ゲームが反則を見てくれるので、そのまま遊べます。

<div class="point"><p class="pointTitle">BILLIARDSの対戦のしかた</p><ul><li>離れている友達とはONLINE VS（URLを送るだけ）</li><li>隣にいる人とはLOCAL VS（1台を交互に）</li><li>スマホとパソコン、iPhoneとAndroidでもクロスプレイできる</li><li>どちらも無料・登録なし・アプリなし</li></ul></div>
