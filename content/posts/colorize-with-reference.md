白黒写真をAIでカラーにして色がしっくりこないときは、**同じ日に撮ったカラー写真を手本にする**と、その日らしい色に近づきます。COLOR RE:FINEの「あの日の色」は、そのための機能です。

<p class="postCta"><a href="/color-refine">COLOR RE:FINEを開く</a></p>

## AIの色が合わないのは、その日の光を知らないから

AIは、たくさんの写真から覚えた「だいたいこういう色」で白黒写真に色を付けます。ただ、AIはその写真を撮った日の天気や時間までは分かりません。

| よくある違和感 | 理由 |
| --- | --- |
| 夕方の写真なのに、昼間のような色 | 光の暖かさが分からない |
| 古い写真なのに、色が鮮やかすぎる | 当時の写真の色の濃さが分からない |
| 室内なのに、明るすぎる | その場の明るさが分からない |

**写っているものの色は推し量れても、その日の光までは分からない**のが、AIのカラー化の限界です。AIの色がどう決まるかは「[白黒写真をカラーにするとき知っておきたいこと](/blog/colorize-old-photos)」に書きました。

## 同じ日のカラー写真から、暖かさ・彩り・明るさを読み取る

アルバムを見返すと、同じ日の写真に白黒とカラーが混ざっていることがあります。そういうときは、カラーの方を手本にできます。

「あの日の色」にカラー写真を入れると、COLOR RE:FINEはその写真から3つのことを読み取ります。

| 読み取るもの | 分かること |
| --- | --- |
| 暖かさ | 夕日のように暖かいか、曇りのように涼しいか |
| 彩り | 色が濃いか、落ち着いているか |
| 明るさ | 明るい光か、深みのある光か |

読み取った結果は「あたたかな色合い・豊かな彩り・やわらかな光」のように言葉でも表示されます。**この空気感を、白黒写真に付ける色に重ねます。**

<div class="kome"><p>写っているものの色をそのまま写し取るわけではない。服や車の色が手本の写真と同じになるわけではなく、全体の色合いが寄る。</p></div>

## 使い方は、白黒写真をカラーにしてからカラー写真を足すだけ

1. COLOR RE:FINEを開いて、白黒の写真を選んでカラーにする
2. 「あの日の色」の欄から、同じ日に撮ったカラー写真を追加する
3. 色味の読み取りが終わるのを待つ
4. 「反映度」で、手本の色をどのくらい効かせるかを決める
5. 左右にドラッグして、元の写真と比べてから保存する

反映度は最初50％になっています。**効きすぎると感じたら下げ、もっと寄せたいなら上げてください。**

<div class="point"><p class="pointTitle">手本にする写真の選び方</p><ul><li>同じ日、できれば同じ時間帯に撮ったもの</li><li>同じ場所（屋外なら屋外、室内なら室内）</li><li>色あせが少なく、明るさが整っているもの</li></ul></div>

## 手本がないときは、Standard・Natural・Softから選ぶ

同じ日のカラー写真がない写真の方が多いはずです。そのときは、3つの色味から選びます。

| 色味 | 仕上がり |
| --- | --- |
| Standard | AIの色をそのまま出す |
| Natural | 少し落ち着かせる（最初はこれ） |
| Soft | さらに控えめにする |

「あの日の色」を使っているあいだは、この3つの色味は選べません。手本の色が優先されます。**使うのをやめたいときは、「使用中」を「使用しない」に切り替えます。**

## 写真はどれも外に送られず、元の写真も上書きされない

白黒写真も、手本のカラー写真も、読み込みとカラー化は**全部ブラウザの中だけ**で行われます。家族の写真をどこかに送る必要はありません。

カラーにした写真は新しい画像として保存されるので、元の白黒写真はそのまま残ります。初回だけAIのデータを約215MB読み込むので、Wi-Fiのあるところで使ってください。紙の写真の取り込み方は「[古いアルバムの写真をスマホのカメラで撮って残すコツ](/blog/digitize-old-album)」にまとめました。
