大人の頭の体操なら、**全5問・時間制限なしで数分で終わるパズル**がちょうどいいです。図形の「ANGLE」、計算の「BLANK」、数列の「SEQUENCE」の3つを、ブラウザで無料で遊べます。

## 3つとも全5問、正解の数と速さでスコアが決まる

| パズル | 解くもの | 例 |
| --- | --- | --- |
| ANGLE | 三角形の角度 | 60°＋50°＋？＝180° |
| BLANK | 式の空欄 | 12＋？＝20 |
| SEQUENCE | 数の並びの規則 | 2、4、6、？、10 |

どれも時間制限はなく、**正解の数と答えるまでの速さ**でスコアが決まります。初級・中級・上級の3段階から選べます。

## ANGLEは三角形の角度、中級からは対頂角を使う

「ANGLE（アングル）」は、示された角度を手がかりに「？」を求める図形のパズルです。

| 段階 | 使う知識 |
| --- | --- |
| 初級 | 三角形の内角の和は180° |
| 中級 | 三角形が2つ、対頂角 |
| 上級 | 三角形が3つ、対頂角 |

向かい合う角は同じ大きさになる「対頂角」は、中学校で習ったのに**意外と忘れている人が多い**ところです。

## BLANKは式の穴埋め、上級はカッコ入りの逆算

「BLANK（ブランク）」は、四則演算の式に空いた「？」に入る数字を逆算するパズルです。

| 段階 | 式の形 |
| --- | --- |
| 初級 | 四則演算が1つ |
| 中級 | 計算の順番が効いてくる |
| 上級 | カッコが入る |

**答えはすべて正の整数**なので、暗算でも解けます。

<p class="postCta"><a href="/bit/blank">BLANKで遊ぶ</a></p>

## SEQUENCEは数列の規則当て、上級は2つの数列が交差する

「SEQUENCE（シークエンス）」は、数の並びから隠れた規則を見つけて「？」を求めるパズルです。

| 段階 | 規則 |
| --- | --- |
| 初級 | 同じ数ずつ増える |
| 中級 | 2つの規則が交互に出る |
| 上級 | 差が変わる、2つの数列が交差する |

ひらめいた瞬間の気持ちよさは、**3つの中でSEQUENCEが一番**です。
