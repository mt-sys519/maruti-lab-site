MarutiBitのゲームは、**どれもブラウザで開くだけで、無料・登録なしで遊べます**。そのときの気分に合わせて選べるように、4つに分けました。

## 頭を使いたいときは、全5問で終わるパズル

| ゲーム | 内容 |
| --- | --- |
| [ANGLE](/bit/angle) | 三角形の角度を求める図形のパズル |
| [BLANK](/bit/blank) | 四則演算の式の空欄を逆算する |
| [SEQUENCE](/bit/sequence) | 数の並びの規則を見抜く |

どれも時間制限なしで、**数分で終わります**。3つの違いは「[大人の頭の体操に5問だけの計算と図形のパズル](/blog/brain-puzzles)」にまとめました。

## 指を動かしたいときは、打つ・弾く・連打する

| ゲーム | 内容 |
| --- | --- |
| [INPUT RAIN](/bit/input-rain) | 落ちてくる日本語を打つタイピングゲーム |
| [AIR HOCKEY](/bit/airhockey) | ゲームセンターのエアホッケー、2人対戦もできる |
| [NEON BREAK](/bit/neonbreak) | ネオンの台で9番を狙うナインボール |
| [HYPER PROP](/bit/hyperprop) | ペダルを連打して空を飛ぶレトロゲーム |

スマホ1台を2人で囲んで遊べるのは、**AIR HOCKEYの2人対戦**です。

## 何もしたくないときは、眺める・触るだけのもの

| ゲーム | 内容 |
| --- | --- |
| [AVENUE](/bit/avenue) | 雨とウインドチャイムを眺めて聴く環境音 |
| [PAKU](/bit/paku) | 水槽の熱帯魚に、タップで餌をあげる |
| [LILT ORB](/bit/liltorb) | 触れると粒子が集まってくる球体 |

勝ち負けも点数もないので、**疲れている日にちょうどいい**です。

## 何か作りたいときは、混ぜる・描く

| ゲーム | 内容 |
| --- | --- |
| [MIX POP](/bit/mixpop) | 6つのジュースを混ぜて、一杯に名前をつける |
| [MAGNET BOARD](/bit/magnetboard) | 砂鉄で描いて、つまみで消す磁気お絵かきボード |

<div class="point"><p class="pointTitle">迷ったときは</p><ul><li>すきま時間なら、パズルかINPUT RAIN</li><li>誰かと一緒なら、AIR HOCKEYの2人対戦</li><li>何も考えたくないなら、AVENUEかPAKU</li></ul></div>

## 迷ったら、各ゲームのページのRANDOMを押す

各ゲームのページの下には「RANDOM」のボタンがあります。**押すと、MarutiBitのどれかのゲームに飛びます。**

<div class="kome"><p>思ってもみなかったゲームが、案外その日の気分に合うこともある。</p></div>

触るだけのおもちゃは「[触るだけで気がまぎれるデジタルフィジェットトイ](/blog/touch-only-stress-toys)」、MIX POPの遊び方は「[ドリンクバーで混ぜて遊んだあの感じをブラウザで遊べるMIX POP](/blog/drink-bar-mix)」で紹介しています。
