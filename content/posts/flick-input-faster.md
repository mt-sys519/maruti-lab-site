フリック入力を速くするなら、**同じキーを何度もタップする打ち方をやめて、フリックだけで打つ**のがいちばんの近道です。1文字が1回の指の動きで決まるので、速く打っても文字が化けません。

<p class="postCta"><a href="/bit/input-rain">INPUT RAINでフリックを練習する</a></p>

## 「う」を打つのに3回タップしていたら、そこが遅さの原因

スマホのかな入力には、2つの打ち方があります。

| 打ち方 | 「う」の打ち方 | 速さ |
| --- | --- | --- |
| トグル入力 | 「あ」を3回タップ | 遅い。同じ行が続くと待たされる |
| フリック入力 | 「あ」を上にはらう | 速い。1文字が1回で決まる |

トグル入力で「ああ」と打とうとすると、2回目のタップが「い」になってしまいます。**同じ行の文字が続くたびに手が止まる**のが、トグル入力の弱点です。

## 「フリックのみ」の設定で、トグルを使えなくしてしまう

フリックに切り替えたつもりでも、つい何度もタップしてしまうものです。思い切って、キーボードの設定でトグル入力を使えなくすると早く慣れます。

- iPhoneは、設定アプリの「一般」→「キーボード」にある「フリックのみ」をオンにする
- Androidは、使っているキーボードアプリの設定で、12キーの入力を「フリック」だけにする

**同じ行の文字を続けて速く打てるようになる**のが、この設定のいちばんの効き目です。

<div class="kome"><p>Androidは、キーボードアプリや機種によって項目の名前が違う。キーボードの設定の「日本語」や「12キー」のあたりを探すと見つかる。</p></div>

## 向きは「左・上・右・下」が「い・う・え・お」

フリックの向きは、どの行でも同じです。

| 指の動き | 出る文字（あ行の場合） |
| --- | --- |
| タップ | あ |
| 左 | い |
| 上 | う |
| 右 | え |
| 下 | お |

左から時計回りに**い・う・え・お**と覚えると、どの行でも迷いません。

## 小さい文字と濁点は、文字を打ったあとに切り替えキーで変える

「っ」「ゃ」や「が」「ぱ」は、先に元の文字を打ってから、左下の切り替えキーで変えます。INPUT RAINのキーボードでは、こう打ちます。

| 打ちたい文字 | 打ち方 |
| --- | --- |
| が | 「か」→「゛゜小」 |
| ぱ | 「は」→「゛゜小」を2回 |
| っ | 「つ」→「゛゜小」を2回 |
| ゃ | 「や」→「゛゜小」 |

INPUT RAINでは「っ」は「つ」→「づ」→「っ」の順に変わるので、**2回押す**のがつまずきやすいところです。スマホのキーボードは、機種によって変わる順番が違うことがあります。

<div class="point"><p class="pointTitle">速くなる練習の順番</p><ul><li>「フリックのみ」の設定にする</li><li>い・う・え・おの向きを指に覚えさせる</li><li>小さい「っ」と濁点を意識して打つ</li></ul></div>

## 毎日20秒、落ちてくる言葉を打って指に覚えさせる

フリックは、頭で考えずに指が動くようになるまで、短い練習を繰り返すのがいちばんです。

私が作った「INPUT RAIN（インプットレイン）」は、落ちてくる日本語を、落ちきる前に打ち込むタイピングゲームです。最初に入力方法で「フリック」を選ぶと、**ゲームの中のフリックキーボードで**そのまま練習できます。

![INPUT RAINのゲーム画面](/games/shots/input-rain.webp)
*落ちてくる日本語を、落ちきる前に打ち込みます*

ゲームの中のキーボードも、向きはこの記事と同じ「左・上・右・下＝い・う・え・お」で、濁点と小さい文字は「゛゜小」キーで変えます。初級は20秒で終わるので、**休憩のついでに1回**から始められます。キーボードでの練習やジャンルの選び方は「[タイピング練習を続けるならゲームでいい](/blog/typing-practice-game)」にまとめました。
