タイピング練習が続かないなら、**実際の日本語を打つゲームで練習する**のが近道です。無料の「INPUT RAIN」なら、ブラウザで開くだけで、キーボードでもスマホのフリックでも練習できます。

## キーの位置を覚えたら、あとは日本語の文章を打つほうが身につく

「asdf」「jkl;」を打つ練習は、キーの位置を覚えるまでで十分です。そこから先は、仕事や日常で実際に打つ日本語をたくさん打つほうが上達します。

ローマ字入力では、次の文字でつまずく人が多いです。

- 小さい「っ」「ゃ」「ゅ」「ょ」
- 「ん」のあとに母音が続く言葉（「原因」「単位」など）
- 長音の「ー」

**こういう文字が混ざった普通の文章を打つ練習が、そのまま役に立ちます。**

## INPUT RAINは、落ちてくる日本語を落ちきる前に打つゲーム

「INPUT RAIN（インプットレイン）」は、画面の上から落ちてくる日本語を、落ちきる前に打ち込むタイピングゲームです。

速く正確に打つほど画面の雨が強くなり、雨粒の音が重なっていきます。手が止まると雨は弱まります。**うまく打てているかどうかが、音と景色でわかります。**

## お題は4ジャンル、制限時間は20秒から180秒まで4段階

| ジャンル | 打つ言葉 |
| --- | --- |
| 日常 | 身近な言葉、日常の一文 |
| 四字熟語 | 意味も一緒に覚えられる |
| ビジネス | メールや会議で使う言い回し |
| 端末 | パソコンの画面のような雰囲気で打つ |

| 段階 | 制限時間 |
| --- | --- |
| 初級 | 20秒 |
| 中級 | 40秒 |
| 上級 | 60秒 |
| PRO | 180秒 |

四字熟語は、打ち終えると意味が表示されます。**タイピングと一緒に言葉も覚えられます。**

## スマホはフリック入力を選べば、そのまま練習できる

INPUT RAINは、最初の画面で入力方法を選べます。

| 入力方法 | 向いている人 |
| --- | --- |
| キーボード | パソコン、またはスマホにキーボードをつないでいる |
| フリック | スマホのかな入力で練習したい |

スマホに物理キーボードをつないでいる場合は、「キーボード」を選んでください。

<div class="kome"><p>PROの文章は長いので、フリックで打ちきるのはかなり大変。フリックなら初級から上級までで十分練習になる。</p></div>

## 続けるコツは、20秒の初級を毎日1回

タイピングは、一度に長くやるより、**短い時間を毎日続けるほうが身につきます**。初級なら20秒で終わるので、休憩のついでに1回遊ぶくらいでちょうどいいです。

ジャンルと入力方法は端末に記憶されるので、次からはSTARTを押すだけで始められます。
