三角形の角度を求める問題は、**4つのきまりを知っていれば、ほとんど解けます**。どのきまりを使うかは、図の中で「三角形」「一直線」「交わった2本の線」を探すと決まります。

<p class="postCta"><a href="/bit/angle">ANGLEで角度の問題を解く</a></p>

## 角度の問題で使うきまりは、この4つ

| きまり | 中身 |
| --- | --- |
| 三角形の内角の和 | 3つの角を足すと180° |
| 一直線の角 | 一直線上にできる角を足すと180° |
| 対頂角 | 2本の直線が交わってできる、向かい合う角は等しい |
| 三角形の外角 | 外角は、となり合わない2つの内角の和に等しい |

このうち**外角のきまりは、内角の和と一直線の角を組み合わせたもの**です。忘れても、上の2つから求め直せます。

## 内角の和は180°、2つ分かれば残りは引き算で出る

三角形の3つの角を足すと、必ず180°になります。2つの角が分かっていれば、残りの1つは引き算です。

例：60°と50°が分かっているとき

1. 分かっている2つを足す：60°＋50°＝110°
2. 180°から引く：180°−110°＝70°

答えは70°です。**角度の問題は、最後はほとんどこの引き算に行き着きます。**

## 一直線は180°、対頂角は等しい

三角形の外に線がのびているときは、一直線のきまりを使います。

| 図に見えるもの | 使うきまり | 例 |
| --- | --- | --- |
| 1本の直線の上に角が2つ | 足すと180° | 110°のとなりは70° |
| 2本の直線が交わっている | 向かい合う角は等しい | 40°の向かいも40° |

対頂角は中学校で習うきまりです。**2本の線が「×」の形に交わっていたら、まず対頂角を疑ってください**。

<div class="point"><p class="pointTitle">図のどこを見るか</p><ul><li>三角形がある → 内角の和180°</li><li>直線の上に角が並んでいる → 一直線180°</li><li>「×」の形の交わり → 対頂角は等しい</li></ul></div>

## 三角形が2つ以上ある問題は、分かる角から順に埋める

三角形が2つ、3つと組み合わさった問題でも、やることは同じです。

1. 角度が2つ分かっている三角形を探して、残りの角を出す
2. 出した角の対頂角や、一直線のとなりの角を書き込む
3. 新しく2つ分かった三角形があれば、また残りを出す
4. 「？」の角にたどり着くまで繰り返す

いきなり「？」を求めようとせず、**分かる角を図に書き込んでいく**と、道すじが見えてきます。

<div class="kome"><p>外角のきまりを使うと、手順を1つ飛ばせることがある。三角形の外側の角が「？」なら、となり合わない2つの内角を足すだけで済む。</p></div>

## ANGLEは、このきまりで解く角度のパズル

私が作った「ANGLE（アングル）」は、示された角度を手がかりに「？」を求める図形のパズルです。全5問で、時間制限はありません。

| 段階 | 使うきまり |
| --- | --- |
| 初級 | 三角形の内角の和 |
| 中級 | 三角形が2つ、対頂角 |
| 上級 | 三角形が3つ、対頂角 |
