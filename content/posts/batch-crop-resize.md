何枚もの画像を同じサイズにそろえるなら、私が作った無料ツール「SwiftCrop」で**まとめて切り抜き・リサイズ**できます。アプリも登録もいらず、ブラウザで開くだけです。

## SwiftCropは画像を何枚でも一度に、同じ設定で切り抜ける

SwiftCropは、選んだ画像をまとめて、同じサイズ・同じ形式に変換するツールです。スマホでもパソコンでも使えます。

- 無料で、会員登録はいらない
- 何枚でもまとめて読み込める
- 切り抜き・リサイズ・形式の変換が一度に終わる
- 画像はブラウザの中だけで処理され、どこにも送られない

1枚ずつ写真アプリで開いて切り抜く必要は、もうありません。

## サイズは使う場所で決める、迷ったらこの4つ

そろえるサイズは、画像を載せる場所で決まります。よく使うのはこのあたりです。

| 使う場所 | サイズ・比率 |
| --- | --- |
| インスタの正方形投稿 | 1080×1080 |
| ブログやWebページの共有画像（OGP） | 1200×630 |
| スマホの縦長の画面 | 9:16 |
| 横長の動画やスライド | 16:9 |

インスタの1080×1080とOGPの1200×630は、SwiftCropの「用途別サイズ」から**ボタン一つで選べます**。

<div class="kome"><p>ネットショップやフリマアプリは、サービスごとに推奨サイズが決まっていることが多い。迷ったら、そのサービスのヘルプに書いてあるサイズに合わせるのが確実。</p></div>

## 保存形式は写真ならJPEG、透明な画像はPNG、自分のサイトならWebP

サイズと一緒に迷うのが保存形式です。

| 形式 | 向いているもの |
| --- | --- |
| JPEG | 写真、SNSに載せる画像 |
| PNG | 背景が透明な画像、ロゴ |
| WebP | 自分のWebサイトに載せる画像 |

JPEGには「品質」の設定があります。**85％にしておけば、見た目はほとんど変わらずにファイルが軽くなります。**数字を下げすぎると、画像が粗くなるので気をつけてください。

## 使い方は4ステップ、画像を選んでサイズと形式を決めるだけ

1. 画像をまとめて選ぶ（パソコンならドラッグ＆ドロップでも入る）
2. 出力サイズを決める（数字を入れるか、比率や用途別サイズを選ぶ）
3. 保存形式と品質を選ぶ
4. 保存する

![SwiftCropの出力サイズと出力設定の画面](/blog/swiftcrop-settings.webp)
*左で出力サイズと形式を決めて、右に画像をまとめて入れます*

一度使ったサイズは「最近使ったサイズ」に残るので、次からは選び直すだけで済みます。

<div class="point"><p class="pointTitle">迷ったらこの設定</p><ul><li>インスタに載せる：1080×1080、JPEG、品質85％</li><li>ブログの共有画像：1200×630、JPEG、品質85％</li><li>透明な部分がある画像：PNG</li></ul></div>

## スマホは1枚ずつ保存、パソコンはZIPでまとめて保存

保存のしかたは2つあります。

| 使っている端末 | おすすめの保存方法 |
| --- | --- |
| スマホ | 1枚ずつ保存・共有（写真アプリに入る） |
| パソコン | ZIPでまとめて保存（1つのファイルで届く） |

ファイル名の欄に「###」を入れておくと、**001、002……と連番を振ってくれます**。空欄なら元のファイル名のままです。

## 画像はアップロードされないので、人の写った写真や公開前の画像にも使える

画像を加工するWebサービスの多くは、画像をいったんサーバーに送っています。SwiftCropは、切り抜きもリサイズも**全部ブラウザの中だけで処理**しているので、画像が外に出ることはありません。

送って待つ時間もないので、枚数が多くても思ったより早く終わります。送らない作りにした理由は「[画像を外部に送信しないWebツールという選択。](/blog/browser-only)」に書きました。
