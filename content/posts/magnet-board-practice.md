「MAGNET BOARD（マグネットボード）」は、子どもの頃に触った磁気お絵かきボードを、**スマホやパソコンのブラウザでそのまま使える**ようにしたものです。ひらがなやたし算のお手本を薄く出して、上からなぞることもできます。

<p class="postCta"><a href="/bit/magnetboard">MAGNET BOARDで描く</a></p>

## ブラウザで開いて、指かマウスでそのまま描く

ページを開くと、赤いボードが出てきます。スマホなら指で、パソコンならマウスでなぞると、砂鉄が集まって線になります。

**アプリのインストールも登録もいりません**。無料で、開いたその場で描けます。

| ボタン | できること |
| --- | --- |
| せんのふとさ | 丸を押して、ほそい・ふつう・ふといの3つから選ぶ |
| 右上の色の丸 | ボードの枠を、あか・あお・きいろに変える |
| 右上のスピーカー | 描く音とつまみの音を出す（最初は消えています） |

速く引いた線は、砂鉄が付ききらずに少しかすれます。ゆっくり描くと、くっきりした線になります。

## 下のつまみを横に滑らせると、通ったところだけ消える

ボードの下にある白いつまみを横に滑らせると、**つまみが通ったところだけ**砂鉄が落ちて消えます。端まで滑らせれば全部消えますし、途中で止めれば半分だけ残せます。

![左は家と太陽を描いたボード、右はつまみを途中まで滑らせて家の左側だけ消したボード](/blog/magnet-board-draw-erase.webp)
*左が描いたところ、右がつまみを途中まで滑らせたところ。つまみが通った左側だけ消えています*

本物のボードと同じで、ひとつ前に戻るボタンはありません。消したら戻らないので、そこは思い切りよく。

## ひらがな・たし算・かたちのお手本を薄く出してなぞれる

ボードの下のボタンで、画面の奥にお手本を薄く出せます。お手本は下敷きのようなもので、**つまみで消してもお手本は残る**ので、何度でもなぞり直せます。

| ボタン | お手本の中身 |
| --- | --- |
| じゆう | お手本なし。好きに描く |
| あいう | ひらがな46文字。あ行からわ行のボタンで、練習したい字を選べる |
| 1+2 | 答えが10までのたし算とひき算。数を数える丸つき |
| ○△ | まる・さんかく・しかく・ほし・ハート・なみ・ギザギザ・うずまき |

![左はひらがなの「あ」のお手本をなぞったボード、右は「6＋2＝」の答えの欄に8と書いたボード](/blog/magnet-board-practice.webp)
*左は「あいう」で「あ」をなぞったところ、右は「1+2」で答えの欄に8を書いたところ*

「あいう」と「○△」は、右の「つぎ」で次の字や形に進みます。「1+2」は、自分で答えを書いてから「こたえ」を押すと答えが出て、もう一度押すと次の問題になります。

ひき算では、数える丸のうち引く数だけに×が付いています。**丸を数えながら答えを書ける**ので、まだ指で数える年齢の子でも解けます。

<div class="kome"><p>「なみ」や「うずまき」のような線のお手本には、描き始めの場所に点が付いている。</p></div>

## 保存はできないので、残したい絵はスクショで

MAGNET BOARDには、描いた絵の保存も、ひとつ前に戻るボタンもありません。描いて、消して、また描く。あのボードと同じ遊び方です。

うまく描けた絵や、子どもが初めて書けた字を残したいときは、**スマホやパソコンのスクリーンショットで保存**してください。
