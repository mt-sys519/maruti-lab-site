FAQ

よくある質問

料金や写真の扱い、色の作り方、保存した画像のこと、うまくいかないときの確かめ方をまとめました。操作の流れは使い方のページで順に説明しています。

使う前に

なんと読みますか？

「フィルミア」と読みます。

無料ですか？

はい、すべての機能を無料で使えます。運営は広告の収益でまかなっています。使える色の数や保存の回数に制限はなく、保存した画像にロゴや透かしも入りません（枠を選んだときに入る色名と16桁の番号は、どちらも外せます）。

会員登録やログインは必要ですか？

必要ありません。ページを開けばすぐに使えます。メールアドレスなどの個人情報を入力する場面もありません。

どの端末で使えますか？

パソコンのブラウザ（Chrome・Edge・Safari・Firefox）と、iPhone の Safari、Android の Chrome の新しめのバージョンで動きます。色の計算に端末の画像処理の機能（WebGL2）を使うため、とても古い端末では開けないことがあります。

アプリとして使えますか？

使えます。ホーム画面に追加すると、アプリと同じように画面いっぱいで開けます。パソコンの Chrome・Edge と Android の Chrome では、右上に出る「アプリとして追加」のボタン（ブラウザのメニューの「アプリをインストール」「ホーム画面に追加」でも同じ）から追加できます。iPhone では Safari の共有ボタンから「ホーム画面に追加」を選んでください。一度開いたあとは通信がなくても開け、使ったことのある色はそのまま使えます。追加しても写真が外に送られることはありません。

どんな写真が使えますか？

JPEG・PNG・WebP など、ブラウザで表示できる写真が使えます。iPhone で撮った HEIC の写真は、Safari から選ぶと自動で JPEG に変換されて読み込まれます。RAW データはそのままでは読み込めないので、カメラやスマホで JPEG にしてから使ってください。

写真と安全性

写真はどこかにアップロードされますか？

されません。写真の読み込み、色の計算、画像の書き出しまで、すべてお使いの端末のブラウザの中で行います。FILMEA には写真を受け取るサーバーそのものがなく、運営者が写真を見ることもできません。

インターネットと通信しているのは何ですか？

画面の書体（Google Fonts）、色のデータ、サンプル写真、広告の読み込みです。書体は Google のサーバーから、色のデータとサンプル写真は FILMEA のサーバーから、広告は楽天市場の広告の配信元から読み込んでいます。どれもファイルを受け取るだけで、あなたの写真や撮影情報は送っていません。広告を押すと楽天市場のサイトに移動します。

広告が出ているのはなぜですか？

FILMEA を無料のまま続けるためです。広告は楽天市場のアフィリエイト広告で、広告から商品が購入されると運営者に紹介料が入ることがあります。広告は写真とは別の枠で動いていて、広告を押しても写真が広告の会社に渡ることはありません。詳しくはプライバシーポリシーをご覧ください。

写真の位置情報（GPS）は保存した画像に残りますか？

残りません。FILMEA は色をかけた写真を一度描き直してから書き出すため、撮影日時・位置情報・機種名などの撮影データ（EXIF）は保存した画像に含まれません。そのまま SNS に載せても、撮った場所が知られることはありません。

色について

色はどうやって作っているのですか？

同じ RAW データを「標準」とそれぞれのモードに現像し分けた画像の組を集め、その2枚の色の差を FILMEA が独自に測って、3D LUT という色の対応表にしています。配布されている LUT やフィルターを流用したものではありません。測るのに使った画像は公開しておらず、FILMEA が配っているのは色の差を表す数値だけです。

実在のフィルムやカメラとまったく同じ色になりますか？

同じにはなりません。FILMEA の色は、測った組の範囲で差を再現したものです。学習に使っていない写真で確かめると、多くの色で 8bit の階調にして平均2〜3段ほどのずれに収まっていますが、測った組に少ない色（たとえば鮮やかな赤や肌の色が少ない系統）は外れやすくなります。雰囲気を手軽に試すための道具として使ってください。

特定のメーカーと関係はありますか？

ありません。FILMEA は Maruti Lab が独自に作っているツールで、特定の企業や製品とは提携・関係していません。色の名前や番号も FILMEA 独自のものです。

どの写真にあてるのがいちばん合いますか？

カメラやスマホで撮ったままの、手を加えていない写真です。色はそうした「標準」の仕上がりを起点に測っているので、すでに色を濃くした写真にあてると強く出すぎることがあります。そのときは効き具合を下げてください。

自分の持っている LUT は使えますか？

使えます。.cube、HaldCLUT の .png、.lut16 の形式に対応しています。くわしくは使い方の「手持ちの LUT」をご覧ください。

保存した画像

保存した画像を仕事や販売に使ってもいいですか？

はい。FILMEA で色をかけて保存した画像の著作権は、元の写真の権利を持つあなたにあります。SNS への投稿、展示、印刷、商用利用など、制限なく自由に使ってください。FILMEA へのクレジット表記もいりません。

保存した画像の大きさはどれくらいですか？

「保存の大きさ」で、元の大きさ・長い辺 2048px・長い辺 1080px から選べます。どれも画質の高い JPEG（品質95）で保存します。元の大きさを選んだときは縮小しません。とても大きな写真で、端末が一度に扱える上限を超える場合だけ、上限まで縮めて読み込みます。

インスタグラムにそのまま載せられますか？

白と黒の枠は、インスタグラムの投稿の比率（縦横 4:5 か正方形）で保存します。大きさを 1080px にすると 1080×1350px か 1080×1080px になり、そのまま載せられます。スライドの枠は 50mm 角の正方形なので、そのまま載せられます。フィルムの枠は、実物の形をそのまま再現しているので、インスタグラムの比率とは違います。

枠に入る16桁の数字は何ですか？

撮影日時と色の番号をつないだ16桁の番号です。たとえば 2026112514320804 なら、2026年11月25日14時32分の写真に、8番目の系統の4番の色をかけたことを表します。フィルムの縁に印字される番号をまねた飾りで、撮影日時は写真の撮影データから読み、撮影データがない写真ではファイルの日時になります。写真そのものには何も書き込まず、枠の余白に入れるだけです。「16桁の番号を入れる」の印を外すと入りません。

iPhone で保存した画像が写真アプリに見当たりません。

Safari で保存した画像は「ファイル」アプリの「ダウンロード」に入ります。ファイルを開いて共有ボタンから「画像を保存」を選ぶと、写真アプリに入ります。

うまくいかないとき

写真を選んでも表示されません。

写真の形式がブラウザで表示できないものかもしれません。RAW や、パソコンの Chrome で開いた HEIC の写真は読み込めないので、JPEG に変換してから選んでください。それでも表示されないときは、ページを再読み込みしてもう一度試してください。

色の見本が表示されない・画面が真っ黒のままです。

お使いのブラウザで WebGL2 が使えない状態かもしれません。ブラウザを最新にするか、別のブラウザで開いてみてください。パソコンでは、ブラウザの設定で「ハードウェア アクセラレーション」が切られていると動かないことがあります。

保存ボタンを押しても何も起きません。

アプリの中のブラウザ（SNS アプリでリンクを開いたときの画面など）では、保存ができないことがあります。Safari や Chrome で開き直してから保存してください。

ここにない困りごとがあります。

お問い合わせフォームからお知らせください。お使いの端末とブラウザ、どの画面で何をしたときに起きたかを書いていただけると、原因を探しやすくなります。
