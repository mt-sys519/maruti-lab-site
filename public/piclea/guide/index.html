HOW TO USE

piclea の使い方

写真を選んで、書体を見比べて、整えて、保存する。piclea でやることはこの4つだけです。このページでは、最初の1枚を作るところから、カルーセルや「型」を使った毎日の投稿づくりまでを、画面に出てくる言葉のまま順に説明します。

写真を選ぶ書体を見比べる編集画面文字を整える写真を重ねる図形背景と比率カルーセル型保存する作品の保管

01写真を選ぶ

最初の画面の「写真をえらぶ」を押すと、スマホの写真ライブラリが開きます。1枚でも、まとめて何枚でも選べます。何枚か選んだときは1枚ずつがページになり、そのままインスタのカルーセル投稿（複数枚の投稿）として作れます。

選んだ写真は、表示と編集が軽くなるよう、長い辺が2048ピクセルになるまで縮めてから使います。この処理はスマホのブラウザの中だけで行われ、写真がインターネットに送られることはありません。

写真がなくても作れますお知らせ画像のように写真を使わない1枚は、あとで説明する「背景」で単色やグラデーションにすれば作れます。

02自分の写真で書体を見比べる

写真を選ぶと、その写真の上に文字を入れた見本が、書体ごとにずらりと並びます。これが piclea のいちばんの特長です。サンプル画像ではなく、あなたの写真とあなたの文章で比べられるので、仕上がりを想像する必要がありません。

  1. 上の入力欄に、入れたい文字を打ちます。改行もそのまま反映されます。
  2. 「日本語」「English」で書体の種類を切り替え、「明朝」「丸ゴ」「手書き」などの分類で絞り込みます。
  3. 気になる書体をタップすると大きく開きます。左右にスワイプすると次の書体へ移れます。
  4. 大きく開いた画面では、文字を指で動かして位置を決められます。
  5. 決まったら「この書体で編集する」を押して、編集画面に進みます。

書体の右上の ★ を押すとお気に入りに入り、分類の先頭の ★ でお気に入りだけを並べられます。文章は「＋ 文章」で増やせて、見比べで書体が替わるのは選んでいる文章だけです。見出しは明朝、日付は細いゴシック、というように1つずつ選んでいけます。

画面の下には、文字の色、横書きと縦書き、大きさの調整が並んでいます。「詳細」を押すと、縁取りや影もここで付けられるので、写真が明るくて文字が沈むときは先に影を付けてから見比べると選びやすくなります。

「一部の文字なし」と出たらその書体に、入力した文字の一部（難しい漢字や記号など）が入っていないという印です。足りない文字だけ別の書体で表示されるので、気になるときは別の書体を選んでください。

03編集画面の見かた

編集画面は、写真が画面いっぱいに大きく出て、操作はいちばん下のバーにまとまっています。バーの中身は、いま選んでいるものに合わせて入れ替わります。

何も選んでいないとき文字・写真・図形を足す、背景、調整、ページ、型。作品全体に関わる操作が並びます。
文字を選んだとき編集・書体・色・飾り・配置・レイヤー。選んだ文字だけが変わります。
重ねた写真を選んだとき差し替え（空の枠なら、はめる）・形・中の位置・調整・フチ・影・レイヤー。
図形を選んだとき色・形・線・影・レイヤー。

バーの項目を押すと、そのすぐ上に調整用の引き出しが開きます。もう一度押すと閉じます。引き出しが開いているあいだも写真は小さくなるだけで隠れないので、全体を見ながら調整できます。

選んでいるものを外すには、写真の外の余白をタップするか、写真の上で何もないところをタップするか、バーの左端の「完了」を押します。何も選んでいない状態が、仕上がりそのままの見え方です。

右上の矢印で、ひとつ前に戻す・やり直すができます。ページの追加や削除も戻せます。

04文字を整える

文字を打ち直す

文字をダブルタップするか、選んでいる文字をもう一度タップするか、文字の上に出る小さなバーの「編集」を押すと、写真を少し暗くした上で文字を打てます。打った文字はすぐ後ろの写真に反映されます。「完了」で戻ります。新しい文字は、何も選んでいないときのバーの「文字」で足せます。

動かす・大きさ・回転

文字はドラッグで動かせます。写真の端や真ん中、ほかの文字・写真・図形の端や中心に近づくと線が出て、ぴたりと揃います。四隅の白い丸を引くと拡大・縮小、枠の下にある矢印の丸を回すと回転です。2本指でつまんで広げたり回したりもできます。

引き出しでできること

  • 書体 … 名前をその書体で書いたボタンが2段に並びます。横に送りながらタップすると、写真の上の文字がその場で変わります。右上の欄に書体名（「よもぎ」でも「Yomogi」でも）や「手書き」のような分類を打つと絞り込めます。太さを持っている書体では、下に「太さ」の段が出て、Light から Bold・Black まで、その書体にある太さだけを選べます。
  • 色 … 文字の色。パレットの最後の虹色の丸から好きな色を選べます。
  • 飾り … 「縁取り」「影」「枠」を切り替えて付けます。影は濃さを300%まで上げられるので、明るい写真の上でも文字がはっきり浮きます。枠は四角・カプセル・丸・だ円から選べ、枠の線も付けられます。使っている飾りには小さな点が付きます。
  • 配置 … 左・中・右揃え、横書き・縦書き、大きさ、折り返し（行の幅）、文字間、行間、位置。大きさ・文字間・行間は、スライダーの右の数字をタップすると数値で打てます。「位置」の矢印は1回で1pxずつ動かし、押し続けると続けて動きます。X・Y（完成画像の左上からの位置）と角度も数値で打てます。
  • レイヤー … 複製、前へ・後ろへ（重なり順）、削除、透明度。
縦書きのコツ縦書きでは句読点やかっこを縦向きの形に置き換えます。書体によって縦向きの字形を持っていないものもあり、そのときは位置を調整して表示します。

05写真を重ねる

何も選んでいないときのバーの「写真」から、背景とは別に写真を重ねられます。旅行の写真の上に小さく料理の写真を添える、といった使い方です。重ねた写真は四角・角丸・丸・だ円に切り抜けて、白いフチと影が最初から付いています。

  • 形 … 切り抜きの形、縦横の比率（元の形・1:1・4:5・3:2）、大きさ、角の丸み。
  • 中の位置 … 枠の中で写真を拡大したり、見せる場所をずらしたりします。
  • 調整 … 重ねた写真だけの色温度や明るさを変えます。くわしくは「背景と比率」の調整をご覧ください。
  • フチ・影 … フチの色と太さ、影の濃さ・ぼかし・ずれ。
  • レイヤー … 複製、重なり順、削除、透明度と、位置（矢印での微調整と、X・Y・角度の数値）。
  • 差し替え … 位置や形はそのままで、中の写真だけを入れ替えます。

写真が入っていない枠（型から作ったときなど）は、写真のマークが入ったベージュの四角で表示されます。タップするとすぐに写真を選べます。

06図形で帯や枠を敷く

文字の後ろに帯を敷きたい、写真の上に白い余白を作りたい、というときは「図形」を使います。何も選んでいないときのバーの「図形」を押すと、画面の幅いっぱいの白い帯が文字の下に入ります。

  • 形 … 四角・角丸・丸（だ円）、幅と高さ、角の丸み。幅と高さは数値でも打てます。「横幅いっぱい」「縦いっぱい」「真ん中へ」のボタンもあります。
  • 色 … 色と濃さ。濃さを下げると、写真が透ける帯になります。
  • 線・影 … 図形のふちの線と、影。
  • レイヤー … 複製、重なり順、削除、位置の微調整と数値。ここの「透明度」は線や影まで含めた図形全体を薄くします（「色」の「濃さ」は塗りだけ）。

写真の上では、四隅の丸で形を保ったまま拡大、辺の真ん中にある小さな四角で片方向だけに伸ばせます。反対側の辺は動かないので、端をそろえたまま長さだけ変えられます。伸ばしている辺は、写真の端や真ん中、ほかの図形や文字の端に近づくとぴたりと止まるので、正方形のすぐ下に帯をすき間なく並べる、といった配置も指先だけでできます。文字の枠と違って文字の大きさとは関係なく形を決められるので、帯の上に好きな大きさの文字を置けます。

07背景と比率

何も選んでいないときのバーの「背景」では、背景を「写真」「単色」「グラデーション」から選べます。単色やグラデーションに切り替えても写真は消えずに残っているので、「写真」に戻せば元どおりです。写真のときは、写真をドラッグして見せる場所を決め、2本指で拡大できます。

同じ引き出しの下で、画像の比率を 4:5・1:1・9:16・元の比率 から選べます。インスタのフィード投稿なら縦長の 4:5、ストーリーズやリールなら 9:16 がおすすめです。比率はカルーセルの全ページで共通です（インスタは1回の投稿の写真をすべて同じ比率にそろえるため）。

背景の写真の色は、何も選んでいないときのバーの「調整」で変えられます。並んでいるのは 明るさ・コントラスト・色温度・色合い・彩度・フェード の6つです。色温度を右へ動かすと黄みの暖かい色に、左へ動かすと青みの涼しい色になり、色合いは右でピンク寄り、左で緑寄りになります。フェードは暗いところを白っぽく持ち上げて、くすんだやわらかい雰囲気にします。「元に戻す」で全部0に戻り、カルーセルのときは「全ページの背景に当てる」で同じ調整を全ページにそろえられます。写真そのものは変わらないので、あとから何度でも変えられます。

08カルーセル（複数ページ）

何も選んでいないときのバーの「ページ」を押すと、ページの一覧が開きます。ページが2枚以上あるときは、写真の下の「2 / 4」のような表示を押しても開けます。

  • 一覧の「＋」で写真を足すと、今のページのデザイン（文字や図形）が入った新しいページができます。
  • 「← 前へ」「後ろへ →」で順番を入れ替え、「このページを外す」で作品から外します。
  • バーの「型」から開くシートの「ほかの写真も全部このデザインにする」で、全ページの文字と飾りを今のページと同じにそろえられます。「コピー」「貼り付け」でページからページへデザインを移すこともできます。

09「型」で毎回の投稿を速くする

「型」は、文字・飾り・図形・重ねた写真の位置を、写真だけ抜いて取っておく仕組みです。毎週のお知らせ、同じ形式の商品紹介、日記のような連載など、見た目をそろえたい投稿で力を発揮します。

型を作る

  1. 気に入った1枚を作ったら、バーの「型」を押します。
  2. 「このページを型にする」を押して、名前を付けます。カルーセルなら「◯枚組の型にする」で表紙と中ページをまとめて取っておけます。

型から作る

  1. 左上のメニューの「型から作る」か、右上の「つくったもの」のアイコンから「型から作る」を開きます。
  2. 型を選ぶと写真選択が開くので、使う写真をまとめて選びます。
  3. 写真は1枚目から順に、ページごとに「背景 → 重ねた写真の枠」の順ではまっていきます。

型のページ数より写真が多いときは、最後のページの型がくり返されます。表紙と中ページの2枚組の型を作っておけば、5枚でも10枚でも同じ調子のカルーセルが作れます。写真枠のない型（単色の背景と文字だけ、など）は、写真選択を飛ばしてそのまま開きます。

編集中のページに型を「当てる」こともできます。背景の写真はそのままで、文字と図形と枠が型どおりになり、重ねていた写真は新しい枠に順に移ります。

「型だけをファイルに書き出す」で、写真を含まない小さなファイルとして型を保存できます。機種変更のときや、同じ型を家族や仕事仲間と使いたいときに便利です。

10保存する・投稿する

  1. 右上の「保存」を押すと、仕上がりの画像が表示されます。
  2. iPhone・iPad では「写真に保存・共有」を押すと共有画面が開きます。「画像を保存」で写真アプリに入り、そのままインスタを選んで投稿もできます。表示された画像を長押しして保存することもできます。
  3. Android では「画像を保存」で「ダウンロード」に入ります。インスタへそのまま送るときは、その下の「共有する（インスタなどへ）」を使います。
  4. パソコンでは「画像を保存」で「ダウンロード」フォルダに入ります。

画像は横幅1080ピクセルの JPEG で書き出します。4:5 なら 1080×1350、1:1 なら 1080×1080、9:16 なら 1080×1920 で、インスタが推奨するサイズと同じです。カルーセルは全ページがまとめて書き出され、ファイル名に 01、02… と番号が付くので、順番どおりに選べます。保存した画像にロゴや透かしは入りません。

11作品の保管とバックアップ

作った作品は、編集するたびに自動でスマホの中に保存されます。右上の「つくったもの」を押すと一覧が開き、続きから編集できます。保存先はこのスマホのブラウザの中で、どこかのサーバーに預けているわけではありません。

そのぶん、ブラウザのデータを消すと作品も消えます。また iPhone の Safari は、しばらく開かなかったサイトのデータを自動で消すことがあります。大切な作品を守るために、次の2つをおすすめします。

  • ホーム画面に追加する … Safari の共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように開けて、データも消えにくくなります。
  • まとめてバックアップする … 「つくったもの」の「全部まとめてバックアップ」で、すべての作品と型を写真ごと1つのファイルにできます。準備ができたらもう一度押して「"ファイル"に保存」を選び、iCloud Drive に置いておきます。機種変更しても、「つくったもの」の「バックアップのファイルから戻す」で元どおりです。同じファイルを何度読み込んでも作品は重ならず、スマホに残っているほうが新しい作品はそのまま残ります。1つの作品だけを書き出したいときは、編集画面のバーの「型」から開くシートの「バックアップをファイルに書き出す」を使います。
Android・パソコンのとき「全部まとめてバックアップ」のファイルは、iPhone と違って「ダウンロード」（パソコンでは「ダウンロード」フォルダ）に保存されます。そのままにせず、Google ドライブや OneDrive などに移しておくと安心です。ホーム画面への追加は、Android では Chrome のメニュー︙の「ホーム画面に追加」または「アプリをインストール」、パソコンではアドレスバーのインストールのボタンからできます。
ホーム画面に追加する前にiPhone では、ホーム画面のアイコンから開いた piclea と、Safari で開いた piclea は、保存場所が別々になります。Safari で作った作品をアイコン側でも使いたいときは、Safari でまとめてバックアップし、アイコン側で「バックアップのファイルから戻す」で読み込んでください。
