使う前に

無料ですか？

はい、すべての機能を無料で使えます。使える書体や作品の数に制限は設けておらず（作品はスマホの空き容量の範囲で保存できます）、保存した画像にロゴや透かしも入りません。

会員登録やログインは必要ですか？

必要ありません。ページを開けばすぐに使えます。メールアドレスなどの個人情報を入力する場面もありません。

アプリをインストールする必要はありますか？

いりません。iPhone の Safari や Android の Chrome など、ふだんのブラウザで動きます。Safari の共有ボタンから「ホーム画面に追加」を選ぶと、アイコンからアプリのように開けて、作品のデータも消えにくくなります。

どの端末で使えますか？

スマホで使うことを第一に作っています。iPhone（Safari）と Android（Chrome）の新しめのバージョンで動きます。パソコンのブラウザでも使え、パソコンではマウスのホイールで拡大縮小もできます。

インターネットにつながっていなくても使えますか？

書体のデータをその都度読み込むため、通信できる状態で使ってください。一度読み込んだ書体はしばらくブラウザに残るので、2回目からは表示が速くなります。写真そのものは通信には使いません。

写真と安全性

写真はどこかにアップロードされますか？

されません。写真の読み込み、文字入れ、画像の書き出し、作品の保存まで、すべてあなたのスマホのブラウザの中で行います。piclea には写真を受け取るサーバーそのものがなく、運営者が写真を見ることもできません。

インターネットと通信しているのは何ですか？

書体のデータの読み込みだけです。Google Fonts の書体は Google のサーバーから、一部の書体は piclea のサーバーから配信しています。どちらも書体のファイルを受け取るだけで、写真や入力した文章は送っていません。

入力した文章はどこかに残りますか？

作品の一部として、あなたのスマホのブラウザの中にだけ保存されます。作品を消すと文章も一緒に消えます。

写真の位置情報（GPS）は画像に残りますか？

残りません。piclea は写真を一度描き直してから書き出すため、撮影日時や位置情報などの撮影データは保存した画像に含まれません。

作品の保存

作りかけの作品はどこに保存されますか？

編集するたびに、自動でスマホのブラウザの中に保存されます。右上の「つくったもの」から一覧を開き、続きを編集できます。保存ボタンを押さなくても消えません。

作品が消えてしまうことはありますか？

ブラウザの履歴やWebサイトのデータを消去すると、作品も消えます。また iPhone の Safari は、しばらく開かなかったサイトのデータを自動で消すことがあります。「ホーム画面に追加」して使うとこの影響を受けにくくなります。大切な作品は、次の質問のバックアップもあわせて使ってください。

機種変更したら作品は引き継げますか？

バックアップのファイルで引き継げます。編集画面のバーの「型」から開くシートで「バックアップをファイルに書き出す」を押すと、写真ごと1つのファイルになります。「ファイル」アプリの iCloud Drive などに置いておき、新しいスマホで「つくったもの」の「バックアップのファイルから開く」を選べば元どおりです。

消した作品は戻せますか？

「つくったもの」から消した作品は戻せません。消すときは確認が出るので、よく見てから消してください。編集中の操作は、右上の矢印で元に戻せます。

「型」とは何ですか？

文字・飾り・図形・重ねた写真の位置を、写真だけ抜いて取っておく仕組みです。型を選んで写真を選ぶと、写真が順番に枠へはまり、いつもの見た目の投稿がすぐにできます。くわしくは使い方の「型」をご覧ください。

型をほかの人と共有できますか？

できます。「つくったもの」の「型から作る」で「型だけをファイルに書き出す」を押すと、写真を含まない小さなファイルができます。受け取った人は「型のファイルを読み込む」で使えます。

フォント

作った画像を仕事やお店の宣伝に使ってもいいですか？

はい。piclea の書体はすべて、SIL Open Font License 1.1 か Apache License 2.0 という、商用利用も認められた無料のライセンスで公開されているものです。作った画像はお店の告知、商品紹介、チラシなどにも自由に使えます。書体ごとの作者とライセンスはフォントとライセンスにまとめています。

いくつの書体が使えますか？

日本語が70書体、英語が138書体です。明朝・丸ゴシック・ゴシック・手書き・ポップ・筆など、インスタの投稿でよく使われる雰囲気を中心に選んでいます。英語の書体は Google Fonts での人気を参考にしています。

「一部の文字なし」と表示されるのはなぜですか？

その書体に、入力した文字の一部が入っていないという印です。手書き風やデザイン性の強い日本語書体は、難しい漢字や一部の記号を持っていないことがあります。足りない文字だけ別の書体で表示されるので、気になるときは別の書体を選ぶか、言い回しを変えてみてください。

縦書きはできますか？

できます。一覧の画面では下のバーの「横書き」を押すと縦書きに切り替わります。編集画面では文字を選んで「配置」→「縦書き」です。句読点やかっこは縦書き用の形に置き換えて表示します。

自分の持っているフォントや、ほかの書体を使えますか？

今は piclea に入っている書体だけを使えます。追加してほしい書体があれば、お問い合わせから書体名を教えてください。無料で使えるライセンスのものは、追加を検討します。

画像の保存と投稿

保存した画像のサイズと画質は？

横幅1080ピクセルの JPEG です。4:5 は 1080×1350、1:1 は 1080×1080、9:16 は 1080×1920 で、インスタが推奨するサイズと同じです。投稿時に縮められて文字がぼやける、ということが起きにくい大きさにしています。

写真アプリに保存するには？

「保存」→「写真に保存・共有」で共有画面が開くので、「画像を保存」を選びます。表示された画像を長押しして保存することもできます。

カルーセル（複数枚の投稿）はどう保存されますか？

全ページがまとめて保存されます。ファイル名の最後に 01、02… と番号が付くので、インスタで選ぶときも順番どおりに並べられます。比率はインスタの決まりに合わせて全ページ同じです。

インスタ以外にも使えますか？

使えます。保存されるのはふつうの JPEG 画像なので、X、LINE、Threads、ブログなど、画像を載せられるところならどこでも使えます。比率は 4:5・1:1・9:16 と、元の写真の比率から選べます。

うまくいかないとき

写真が読み込めません。

iPhone で撮った HEIC 形式の写真は、パソコンの Chrome などでは開けないことがあります。iPhone の Safari で選ぶか、JPEG に変換してから選んでください。とても大きな画像や、壊れているファイルも読み込めないことがあります。

書体の表示が遅い、一覧がなかなか出てきません。

書体は画面に近づいたものから順に読み込んでいます。日本語の書体はデータが大きいため、通信が遅いと時間がかかります。電波のよい場所で開くか、Wi-Fi につないでみてください。一度読み込んだ書体は2回目から速くなります。

「写真に保存・共有」を押しても何も起きません。

ブラウザによっては、共有画面をタップの直後にしか開けないため、1回目で開かないことがあります。もう一度押してみてください。それでも開かないときは、表示された画像を長押しして保存できます。

文字を選んだまま外せません。

写真の外の余白か、写真の上で何もないところをタップすると外れます。いちばん下のバーの左端にある「完了」でも外せます。

「つくったもの」に作品が見当たりません。

作品は、作ったときと同じ端末・同じブラウザの中にだけ保存されています。Safari で作ったものは Chrome では見えず、ホーム画面に追加したアイコンと Safari のあいだでも別々になることがあります。作ったときと同じ開き方で確かめてみてください。

ここにない困りごとがあります。

お問い合わせフォームからお知らせください。お使いの端末とブラウザ、どの画面で何をしたときに起きたかを書いていただけると、原因を探しやすくなります。
